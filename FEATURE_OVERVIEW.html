Blocking Validations

Conversion is halted when:

  • Project is already AS6 format
  • Obsolete/unsupported hardware is detected
  • AR version is below B4.25
  • VC3 visualization components are present (not convertible)

Automated Conversion Pipeline

These conversions run automatically in priority order:

1
Project File (.apj) Conversion
XML declaration, AS6 namespace, Version attribute, nested IEC → attribute format, GCC 4.1.2 → 11.3.0, adds Communication/ANSIC/Variables elements
2
Library Replacements 60+ libraries
Updates both Package.pkg / .sw references AND all code files (.st, .var, .typ, .fun). Duplicate-aware: if replacement exists, old entry is removed.
3
Function Call Replacements 100+ mappings
strlen → brsstrlen, memcpy → brsmemcpy, memset → brsmemset, memcmp → brsmemcmp, and 50+ more across all mapped libraries
4
Motion Type Replacements
30+ McAcpAx* types renamed to McAxis* / Mc* equivalents used in AS6
5
Technology Package Version Updates
Updates .lby version references for all 8 tracked technology packages to their AS6 versions
6
OPC UA Conversion
OpcUA/ → OpcUaCs/ folder rename, UAD FileVersion 7/9 → 10, security hardening, package reference updates
7
MpAlarmX Restructuring
Single .mpalarmxcore split into 4 files: *_1 (core), *_L (list), *_C (category), *_Q (query)
8
MpComGroup Restructuring
Removes Linking/Subnodes patterns, preserves parent relationships
9
MpDataRecorder Restructuring
Reorganizes groups (Memory/Record/File), expands alarm configuration (3 defaults)
10
User Configuration
Clears incompatible password hashes, injects BR_Engineer role
11
mappView Anonymous User Config
Updates .mappviewcfg for AS6 anonymous user handling

If the replacement library already exists in the project, the deprecated entry is simply removed. If it doesn't exist, the old entry is renamed in place. This prevents duplicates in Package.pkg.

File Handling

Path-Based Filtering

IncludedExcluded
Logical/ (all contents)Temp/ (build artifacts)
Physical/ (all contents)Binaries/ (compiled output)
.apj files (project root)Diagnosis/ (diagnostic data)
.git, .svn, __MACOSX
No extension whitelist — all files in included paths are processed.

Special Handling

  • Binary files: 50+ extensions (.a, .o, .br, .lby, .vax, .dtm…) — base64 stored, excluded from analysis, passed through unchanged
  • Encoding: UTF-8 with multi-byte validation, Windows-1252 fallback for legacy B&R characters
  • Name limits: 32-char AS6 element ID limit (smart truncation at camelCase boundaries), 10-char mapp component file name limit

Running the Tool

$ python -m http.server 8000
# Open http://localhost:8000/as4-to-as6-converter.html

No dependencies, no build step, no installation. Runs entirely in the browser.
